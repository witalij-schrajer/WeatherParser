- Library `WeatherParser.Parsing.dll`: 2030 method bodies with identical IL, 4270 identical type, method, field and property names, identical assembly references, no manifest resources; the assembly version is 1.0.0.0 instead of 0.1.0.0.
- CLI `WeatherParser.dll`: 795 method bodies with identical IL and 1590 identical names; the only differing assembly reference is `WeatherParser.Parsing` 1.0.0.0 instead of 0.1.0.0.
- `compare-packages.ps1`: in the package `README.md`, the nuspec, the DLL and the package metadata member differ; in the CLI archive the two DLLs, `WeatherParser.deps.json` and the PDB.

So the behavior of the library and the CLI is that of the accepted P9 candidate; the differences are the version, the commit-derived identity data and the README.
