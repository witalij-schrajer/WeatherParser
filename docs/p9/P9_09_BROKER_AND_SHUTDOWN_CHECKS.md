## 6. Limitations of this evidence

- A self-signed test CA given in `Tls.CaFile`: the system trust store and a public CA were not used (plan risk a).
- One broker product (Mosquitto 2.1.2); denial reason codes differ between products (plan risk b). An ACL denial of a single message was not provoked; with MQTT 3.1.1 such a denial stays undetectable (CL-13).
- The successful CLI run published synthetic OsthessenWetter data to the test broker; this is not a publication of OsthessenWetter values (OW-14 unchanged).
- The broker ran on Windows; on the NanoPi the connection went through the SSH tunnel to the device's loopback interface, so the device-side network path is the tunnel, not a LAN connection to a broker.
- The planned successful `--ParseDWD` run was replaced by `--ParseOstHessen`, because the offline fixture set has no DWD `now` archives (P9.07 section 8); the MQTT path, TLS and authentication are the same for every command.
