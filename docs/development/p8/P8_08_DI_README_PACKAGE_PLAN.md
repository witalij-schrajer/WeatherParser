## 1. Goal and Scope
Goal: document the MQTT serializer and the complete library for consumers and bring the status documents in line with the implemented state.
In scope: README section "MQTT serializer (library)": message types and supported roots, templates and placeholders, validation rules, QoS and retain defaults, payload equality with the JSON export, the payload bound and its limit (it bounds message acceptance, not the memory of JSON serialization, C-10), error IDs, the DI registration (`MqttTopicOptions` registered by every consumer of `AddWeatherParsing`, as the other options types), the transport boundary (no broker, credentials or TLS in the library; P3), the duplicate-handling rule of MQ-15 exactly as approved (a message is a duplicate only when its payload is byte-identical to another; timestamps alone, the dataset `measured_at` (C-55) or the per-quantity `measured_at` values, are no duplicate key; for forecasts `source` and `issued_at` identify the run, and a later message of the run replaces the retained one), the OW-14 restriction; the README list of options types every consumer registers; the schema compatibility note (C-105, C-121) restated for consumers; README feature status of the MQTT serializer from planned to implemented; the status passages of AGENTS.md, DEVELOPMENT_PLAN.md and PHASE_P1_PLAN.md; package check.
Out of scope with owner: CLI documentation → P3; release notes → P9.
