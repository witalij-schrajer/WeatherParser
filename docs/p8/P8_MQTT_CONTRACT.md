## 4. Payload bound arithmetic (MQ-11)

From F10 to F12, for a topic of T UTF-8 bytes and an empty MQTT 5.0 property set:

- MQTT 3.1.1, QoS 1 or 2: payload ≤ 268 435 455 − (2 + T) − 2 = 268 435 451 − T
- MQTT 5.0, QoS 1 or 2: payload ≤ 268 435 455 − (2 + T) − 2 − 1 = 268 435 450 − T
- QoS 0 omits the packet identifier and allows two bytes more in both versions.

Proposed bound (MQ-11 A): the library uses the smallest of these for every QoS, **268 435 450 − T**, so that a message fits either protocol version at any QoS. With T at most 65 535 (F1) the protocol bound is never below 268 369 915 bytes. Properties that a transport adds (MQTT 5.0 user properties, message expiry and similar) and broker limits (the MQTT 5.0 Maximum Packet Size, configured broker limits) are not known to the serializer; they reduce the space further and belong to the transport (P3), and consumers can lower the bound with `MaxPayloadBytes`.
