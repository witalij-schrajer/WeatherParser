## 3. Verified source facts

### 3.1 CDC 10-minute station lists

- Each `now/` product directory publishes one station list `zehn_now_<code>_Beschreibung_Stationen.txt` (codes `tu`, `ff`, `rr`, `sd`; also `tx` and `fx` for extreme temperature and extreme wind, not used) and a separate `_partner.txt` list (not used).
- Encoding ISO-8859-1 (for example `Großenkneten` is stored as byte 0xDF), CRLF line endings, line 1 a German header (`Stations_id von_datum bis_datum Stationshoehe geoBreite geoLaenge Stationsname Bundesland Abgabe`), line 2 dashes, data lines padded with spaces to 1000 characters.
- The dash widths of line 2 do not match the data columns. Data layout verified on every record of the four files (zero-based character positions, inclusive): station ID 0–4 (5 digits, leading zeros, for example `00044`); from-date 6–13 and to-date 15–22 (`yyyyMMdd`); altitude within 23–38, latitude within 39–50, longitude within 51–60 (right-aligned, surrounding spaces); positions 60, 101 and 142 are spaces; station name 61–100; federal state 102–141; release status from 143 (all records `Frei`); padding to 1000 characters.
- Records 2026-10-21: `tu` 465, `ff` 277, `rr` 1375, `sd` 66; no duplicate IDs; union 1445 stations; stations present in several lists have identical altitude, coordinates and name (0 conflicts); latitude 47.2689–55.011, longitude 6.0244–14.9506; no empty altitude, no to-date after 2026-10-21.
- To-date lag against 2026-10-21: `tu` 459 of 465 at 0 days, then 1, 2, 6, 29, 81 and more days; `ff` 208 at 0 and 67 at 1 day, then 6 and 81; `rr` 911 at 0 and 442 at 1 day, a tail up to 91 days and more; `sd` 65 at 0 days and one at 195 days. A list therefore contains stations that stopped reporting.
- Time zone of the list dates: not stated in the descriptions ("temporal data coverage per station"). For 463 of the 464 air-temperature stations that have a `now` archive the to-date equals the UTC date of the last `MESS_DATUM` (one is the previous day); at the time of the snapshot (about 04:20 UTC) the UTC and German local dates coincide, so this does not distinguish UTC from local dates. SC-03 treats the dates as UTC dates (assumption).
- Parameters (EN descriptions, missing value `-999`, quality `QN`, time stamps UTC from 2000): air temperature `PP_10` air pressure at station altitude (hPa), `TT_10` air temperature 2 m (°C), `TM5_10` 5 cm, `RF_10` relative humidity (%), `TD_10` dew point; wind `FF_10` mean wind speed (m/s), `DD_10` mean wind direction (°); precipitation `RWS_10` precipitation sum of the previous 10 minutes (mm), `RWS_DAU_10` duration, `RWS_IND_10` indicator; solar `GS_10` sum of global radiation during the previous 10 minutes (J/cm²), `DS_10`, `LS_10`, `SD_10`; extreme wind `FX_10`, `FNX_10`, `FMX_10`, `DX_10` (gust and extreme values). No product provides illuminance.
- Per-station data files in each `now/` directory: `10minutenwerte_TU_<id>_now.zip`, `10minutenwerte_wind_<id>_now.zip`, `10minutenwerte_nieder_<id>_now.zip`, `10minutenwerte_SOLAR_<id>_now.zip` (about 2 KB; one `;`-separated text member; `STATIONS_ID` written without leading zeros, for example `44`; missing value `-999`); a station without a file answers HTTP 404.
- Evidence-file layout (all 466 air-temperature archives and one sample each of wind, precipitation and solar): exactly one member `produkt_zehn_now_<code>_<from>_<to>_<id>.txt` (at most 12232 bytes unpacked, 52–170 rows), ASCII text, CRLF; header `STATIONS_ID;MESS_DATUM;  QN;<columns>;eor` with the columns `PP_10;TT_10;TM5_10;RF_10;TD_10` (`tu`), `FF_10;DD_10` (`ff`), `RWS_DAU_10;RWS_10;RWS_IND_10` (`rr`), `DS_10;GS_10;SD_10;LS_10` (`sd`); `MESS_DATUM` `yyyyMMddHHmm` in UTC; values right-aligned with spaces, missing `-999`.
- List and archive sets differ slightly: the air-temperature `now/` directory holds archives for `02362` and `06272`, which are not in its list, and none for the listed station `00850` (2026-10-21).
- Column coverage in the current air-temperature data of all 466 stations (2026-10-21): `PP_10` has no valid value at 286 stations, `TM5_10` at 9, `TT_10`, `RF_10` and `TD_10` at 1 (`02362`). Membership in a product list therefore proves neither each quantity nor current readings (REQ-024).
- Licence: the descriptions state "The Creative Commons BY 4.0 - Licence "CC BY 4.0" apply".

### 3.2 MOSMIX station catalog

- Encoding ISO-8859-1 (non-ASCII bytes such as 0xC9 in `SANTARÉM`; not valid UTF-8), LF line endings, line 1 header `ID    ICAO NAME                 LAT    LON     ELEV`, line 2 dashes, 5649 records, no duplicate IDs.
- Layout verified on all records: ID characters 0–4 trimmed (5-character IDs and 4-character IDs right-aligned with a leading space, for example ` A051`; patterns `99999` 2696, `A9999` 1513, `A999` 1440; 575 IDs with a leading zero), ICAO characters 6–9 (`----` = none, 2652 records), name characters 11–30 (20 characters, truncated by the source, for example `FLENSBURG (SCHAEFERH`), then latitude, longitude and elevation as whitespace-separated right-aligned fields.
- Latitude and longitude are degrees and minutes written `[-]D.MM` (two minute digits; negative = south or west; for example `JAN MAYEN 70.56 -8.40` is 70°56′N 8°40′W); elevation is an integer in metres (−350 to 4670; no empty value observed).
- One record has a minute part of 60: `37531 ---- GORI                  41.60   44.07   132`.
- The catalog contains worldwide locations; 1384 records lie roughly within the German bounding box.
