## 5. Procedure
No slice changes behavior, so there is no Red step. The orchestrating agent writes all text (documentation is not generated by qwen) and verifies every fact.

### S1 Source facts
- One GET each of the `/messwerte/` page, robots.txt and the imprint with a descriptive User-Agent, no retries; status, content type, bytes, SHA-256 and UTC time recorded.
- Structural facts re-checked against the planning check; every difference recorded; the assumptions the parser relies on listed one per line (table labels, header labels in order, cell order, status titles, time grammar `HH:MM Uhr`, unit suffixes, decimal separator, malformed references observed).
- Source conditions: imprint statements on copyright and reproduction, liability, robots.txt, no licence, no API, no frequency rule.

### S2 Package evaluation
- For AngleSharp and HtmlAgilityPack: latest stable version, licence file, release date, maintenance activity, target frameworks, transitive dependencies, behavior on the observed malformed references (checked with a small local probe on synthetic markup, kept outside the repository), resource loading defaults.

### S3 Contract draft and Codex loop
- OW-01 to OW-16 written with options, recommendation and the verified facts; Codex five-angle review read-only, rounds until 0 findings or the tenth round; every finding verified and either fixed or rejected with reason; every round's output and finding count recorded in the contract.

### S4 User approval
- The user approves or amends each OW row; the approval wording and date recorded; rejected options kept as rejected alternatives.

### S5 Reconciliation
- The phase plan and step plans P6.03 to P6.11 updated where the approved contract differs; leftover "Proposed" labels for approved items removed; Codex review of the reconciliation; checkpoint commit on the user's request.
